# 🎤 음역대 노래 추천 앱

내 목소리 음역대에 맞는 노래를 찾고, 노래방에서 얼마나 키를 조절해야 하는지 알려주는 웹 앱입니다.

## 📖 프로젝트 소개

저음이거나 고음인 사람들은 노래방에서 매번 키를 조절해야 합니다. 하지만 노래마다 얼마나 조절해야 하는지 찾아보는 것은 번거롭습니다. 이 앱은 그런 불편함을 해결합니다!

### 주요 기능

- **음역대 입력**: 최저음과 최고음을 선택하거나 프리셋 사용
- **노래 추천**: 음역대에 맞는 노래 리스트 표시
- **키 조절 가이드**: 각 노래를 부르기 위해 필요한 키 조절 정보 제공
- **필터 기능**: 조정 없이 부를 수 있는 노래만 보기

## 🚀 시작하기

### 필요 사항

- Node.js 18 이상
- npm 또는 yarn

### 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```

## 🎯 사용 방법

1. **음역대 설정**: 자신의 최저음과 최고음을 선택하거나 프리셋(베이스, 바리톤, 테너 등)을 선택하세요.
2. **노래 확인**: 추천된 노래 목록에서 부를 수 있는 곡을 확인하세요.
3. **키 조절**: 키 조절이 필요한 경우, 노래방 리모컨에서 해당 키만큼 올리거나 내리세요.
4. **필터 사용**: "조정 없이 부를 수 있는 곡만" 버튼으로 필터링하세요.


## 🎵 음역대 프리셋

- **베이스** (낮은 남성): E2 ~ E4
- **바리톤** (일반 남성): A2 ~ A4
- **테너** (높은 남성): C3 ~ C5
- **알토** (낮은 여성): F3 ~ F5
- **메조소프라노** (일반 여성): A3 ~ A5
- **소프라노** (높은 여성): C4 ~ C6

## 💡 핵심 알고리즘

### 음정 변환
- 각 음을 숫자로 변환 (C0 = 0, C#0 = 1, D0 = 2, ...)
- 반음 단위로 계산하여 정확한 음정 차이 측정

### 키 조절 계산
1. 노래의 중간 음역대를 사용자의 중간 음역대에 맞춤
2. 조정 후에도 사용자 음역대 안에 들어가는지 확인
3. 필요시 미세 조정하여 최적의 키 조절 값 제공
